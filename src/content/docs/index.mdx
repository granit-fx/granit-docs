## Why Granit?

<CardGrid>
  <Card title="Modular by design" icon="puzzle">
    93 NuGet packages. Pick only what you need — each module is independent with
    explicit `[DependsOn]` declarations.
  </Card>
  <Card title="Multi-provider" icon="setting">
    Swap implementations without changing your code. In-memory for dev, production
    providers for deployment.
  </Card>
  <Card title="Compliance built-in" icon="approve-check">
    GDPR, ISO 27001, and ISO 9001 compliance baked into every module — audit trail,
    encryption, soft delete, data filtering.
  </Card>
  <Card title="Production-ready" icon="rocket">
    Battle-tested in healthcare and government applications. Observability,
    background jobs, multi-tenancy included.
  </Card>
</CardGrid>
