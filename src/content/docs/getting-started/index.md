Welcome to Granit. This section walks you through creating your first application
with the framework.

## Prerequisites

- .NET 10 SDK
- A code editor (Visual Studio, Rider, or VS Code with C# Dev Kit)
- Docker (for integration tests and local infrastructure)

## What you will build

A minimal API with module system, persistence, and authentication — the typical
starting point for a Granit application.
